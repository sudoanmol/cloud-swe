Run a bash command in the sandbox. Returns combined stdout and stderr, truncated to the last 2000 lines or 50KB; when truncated, the full output is saved to a file in the sandbox. There is no default timeout, so a command runs until it exits; set `timeout` in seconds to bound it. Redirect a background process's output to a file, because a process still writing to the tool's output is cut off when the command ends.
